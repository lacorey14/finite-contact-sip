# Finite electronic contacts in spectral induced polarization

This repository contains the numerical code, archived outputs, and figure
reproduction files supporting the manuscript **“Finite Electronic Contacts in
Spectral Induced Polarization: Relaxation, Directionality, and Scale
Dependence.”**

## Repository contents

- `code/`: full-FEM, reduced-network, analysis, verification, and plotting scripts.
- `results/topology_research/`: archived raw and processed numerical outputs.
- `REPRODUCIBILITY_MAP.md`: correspondence among manuscript Figures 1–8,
  source data, and generating scripts.
- `meshes/`: output location for meshes regenerated by the full-FEM scripts.

The archived numerical outputs are sufficient to regenerate all quantitative
main-figure panels without rerunning the full finite-element calculations.
Full recomputation requires Gmsh and can take substantially longer.

## Software environment

Python 3.10 or newer is recommended. Install the Python dependencies with:

```bash
python -m pip install -r code/requirements.txt
```

Gmsh 4.11 or newer must also be available on `PATH` for mesh generation.

## Reproduction levels

1. **Figure regeneration:** use archived JSON/CSV outputs with the plotting
   scripts listed in `REPRODUCIBILITY_MAP.md`.
2. **Derived analysis:** rerun the relevant `analyze_*.py` scripts against the
   archived raw outputs.
3. **Full recomputation:** rerun the `run_*.py` and `verify_*.py` scripts. This
   regenerates meshes and full-FEM solutions and may require substantial time.

Run scripts from the repository root while keeping the archived directory
structure unchanged. Plotting scripts write regenerated files to their original
paths under `results/topology_research/`. For example:

```bash
python code/plot_jgr_topology_benchmark_main.py
```

## Numerical conventions

- Harmonic convention: `exp(+i omega t)`.
- Reported imaginary conductivity follows the sign convention used in the
  manuscript and archived tables.
- Conductance is in siemens, conductivity in S m^-1, frequency in hertz, and
  geometric dimensions in metres unless a file states otherwise.
- Random-network calculations use stored master and design-specific seeds; the
  archived raw outputs retain realization identifiers.
